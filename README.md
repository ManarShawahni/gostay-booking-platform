# GoStay – Travel & Accommodation Booking Platform

GoStay is a hotel booking platform built with React and TypeScript, following a clean feature‑based architecture.

---

## Features Overview (Page Names Only)

- Home Page  
- Search Results Page  
- Hotel Details Page  
- Checkout Page  
- Confirmation Page  
- Admin Dashboard

---

## Project Architecture (Feature-Based)

```
src/
 ├── components/
 │    ├── common/
 │    └── features/
 │         ├── home/
 │         ├── search/
 │         ├── hotel/
 │         └── checkout/
 │
 ├── pages/
 │    ├── Home
 │    ├── SearchResults
 │    ├── HotelDetailPage
 │    ├── CheckoutPage
 │    └── ConfirmationPage
 │
 ├── hooks/
 ├── services/
 ├── context/
 ├── types/
 ├── styles/
 └── routes/
```
